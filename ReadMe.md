**Tip Calculator**
Bilt a Tip Calculator that inputs; bill amount, tip percentage, and number of people, and gives outputs by calculating total bill + tip percentage, and also evenly distribute bill amount among given number of people.

**Link** : https://tip-calculator-three-pearl.vercel.app

**Guidelines to run it locally**
1- Simply download the files in the repository
2- Copy and paste the files into a newly created local folder 
3- Open an IDE of your choice (for e.g) VSCode
4- Select and open the folder, in which you have paste the downloaded files
5- Run, test, and can edit the code
